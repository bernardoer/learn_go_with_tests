# Learn Go with Tests

This repository contains the code I wrote while following the Learn Go with Tests course.

Available at: https://quii.gitbook.io/learn-go-with-tests

I followed the Go Fundamentals and Testing Fundamentals courses in that order.

- Folders from `01_hello_world` to `20_arrays_and_slices_with_generics` contain the exercises and examples from the Go Fundamentals section.
- `21_intro_to_acceptance_tests` and `22_scaling_acceptance_tests` belong to the Testing Fundamentals section.

The project was developed using Go 1.26.0 on Ubuntu 26.04.

## Running the examples

To run the code, go to the folder you want to test and run:

```bash
cd 01_hello_world
go test
```
